# Pygame Zero 创作与教学路线图

## 当前交付约定（2026-10-24 用户补充）

先实现和验证网页版，等待用户确认网页无问题后，再按用户要求一次性生成桌面版。网页修改期间不重新打包、不更新 release/ 中的桌面产物。此约定同时保存在根目录 AGENTS.md，供后续开发遵守。

保持界面简洁、操作方便。新增功能优先复用现有入口，并按当前工具和选择状态显示相关操作，避免持续堆叠按钮和设置。常用操作应容易发现、步骤简短，复杂选项按需展开。每轮功能验收同时检查界面复杂度和操作便利性。此约束同时保存在根目录 AGENTS.md。

Pygame Zero 预览和导出的角色位置统一四舍五入为整数，编辑器内部保留小数。纯色背景在网页中显示实际颜色，关闭画布的透明棋盘格背景图。

当前状态：第二轮 A、B 网页功能已实现，等待用户确认网页版；本轮未运行桌面打包、未更新 release/。详细验收结果见下方第二轮记录。

### 首轮约定

背景尺寸为正整数，每边不超过 32767，总像素不超过 6400 万。重新创建画布 / 替换背景需要确认，确认后清空图层；改颜色保留图层。新项目保存 v3，旧项目继续可读。

名称去掉末尾 png/jpg/jpeg/webp 扩展名后须符合 `[a-z][a-z0-9_]*`，不得重名、使用 Python 关键字或 Pygame Zero / 生成代码保留名称。不自动改名，报错并定位到图层。

项目默认名 pygame_project，结构为 main.py、images/，图片背景固定 background.png，角色统一 PNG。窗口按画布尺寸，导出中心坐标四舍五入为整数，角色逐个创建和绘制。使用 import pgzrun / pgzrun.go()，不生成游戏行为。预览即实际代码，导出快照不修改项目。桌面沿用便携目录限制，拒绝覆盖已有目录，失败清理临时数据。

## 第二轮：精确编辑与多选排列（网页已完成，待用户确认）

- [x] 画布下方独立属性栏：单选输入 X、Y、宽、高，多选输入整体位置、只读整体宽高；顶部不新增按钮。
- [x] 定位点默认中心，可切换左上角；支持小数、Enter / 失焦提交、Esc 恢复及无效输入保护。
- [x] 图片强制保持比例，图形数值输入可关闭比例锁定；越界按可用空间限制并显示实际值。
- [x] Shift / Ctrl / Command 点击加选、空白拖动完整包含框选、修饰键追加、全选及取消；支持图片与图形混选。
- [x] 整体拖动、方向键微调、整体边界限制和以选区外框计算辅助线；不增加整体缩放或持久化分组。
- [x] 六种对齐、水平 / 垂直边缘等间距分布；固定首尾、空间不足禁用，图层顺序保持不变。
- [x] 批量复制、剪切、粘贴、删除；复制快照保持样式与相对位置，跨更小画布整体缩小；卡片删除仍只作用于该对象。
- [x] 每张图片图层下方的锚点坐标默认折叠，图层列表独立滚动；界面简洁、操作方便已加入长期约束。
- [x] 沿用 v3 保存，兼容 v1 / v2；Pygame Zero 角色位置继续四舍五入为整数。
