# 图片摆放与坐标工具设计

用户已确认 Vue 3、TypeScript、Vite 的本地网页方案。

## 行为

加载一张 PNG、JPEG、WebP 背景，并叠加任意数量的同格式角色或物品图片。拖动调整位置；四个角控制点固定对角并保持原始宽高比例缩放。矩形含透明留白，完整限制在背景内。新图片按原始尺寸居中，过大时等比例缩小。后添加的图层在上方，列表反向显示以便选择被遮住的图片。

背景左上角为 (0, 0)，所有尺寸和位置以背景原图像素保存。屏幕仅缩放显示，不改变原图几何数据。显示坐标和坐标导出独立四舍五入两个端点；项目保存精确小数。

提供坐标 JSON 下载 / 复制、包含图片数据的版本 1 项目 JSON 保存 / 恢复，以及原始背景分辨率的合成 PNG。Canvas 按图层顺序绘制，不含控件。项目读取在验证完整格式、所有图片、比例和边界后才替换当前内容。加载图片批次失败不部分添加。替换背景需确认并清空叠加图片。

## 架构

Vue Composition API 管理项目及选择状态，HTML 图片和 Pointer Events 处理交互，ResizeObserver 自动适配显示比例。几何纯函数、项目序列化验证、文件处理与界面分离。图片使用嵌入式 data URL 保存在项目中，禁止项目引用远程图片。无需后端、用户账户或第三方图床。

## 验证

单元测试覆盖坐标转换、居中适配、移动边界、所有角的等比例缩放和极端拖拽、项目精度 / 顺序恢复、端点取整、无效项目拒绝。浏览器验证图片加载、拖动缩放、窗口变化、遮挡选择、保存恢复、PNG 和坐标导出、替换确认及错误时保留当前项目。

## 第一版边界

不支持旋转、裁剪、多背景、图层重排、撤销重做或自动保存。提供未保存项目关闭提示。极大图片受浏览器内存和 Canvas 最大尺寸限制。
