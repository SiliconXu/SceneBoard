# 紧贴名称、图标删除和图层排序

名称在对象正下方紧贴下边缘，居中显示。所有名字层位于所有对象层下方，保证名字不遮住其他角色的可见像素；坐标仍位于所有对象之上。PNG 同步按背景、名字、对象、坐标的顺序绘制。

图层卡片右上角放置垃圾桶图标，具有删除对象的可访问标签和名称提示，点击只删除该卡片对象，不触发卡片选择。删除未选中对象保持选择；删除选中对象选择相邻对象。键盘 Delete / Backspace 保留。

图层卡片支持 HTML 拖拽，卡片上 / 下半部决定插入目标的前 / 后。拖拽显示插入线，取消不修改列表，释放后提交排序。侧栏从顶层到底层展示，存储数组从底层到顶层；纯函数完成顺序转换。排序不改变坐标、尺寸或选择，标记项目未保存，既有项目无需升级。

验证包含顶层 / 底层 / 中间排序与原数组不变、实际浏览器拖拽、卡片删除、名称与角色重叠时的 PNG 像素、排序后的 PNG 像素、保存和恢复顺序，保留原功能验收。
