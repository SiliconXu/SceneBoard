# 图片锚点、图形配色和快捷键

依据用户提供的角色锚点示意图，图片选中时仅在画布中心标记 center 坐标。右侧选中图片以 3×3 网格显示九个矩形锚点：topleft、midtop、topright、midleft、center、midright、bottomleft、midbottom、bottomright。未选中图片卡片保持简要信息；图形仍在画布显示左上角、右下角，详情增加 center。

坐标与名字标签背景分别为 68% 蓝色和 65% 白色，文字不透明。所有名字放在独立覆盖层，所有坐标使用更高的覆盖层，确保不同对象之间仍遵循坐标优先。PNG 先绘制名称再绘制坐标，图片导出中心坐标，图形导出两个角。坐标 JSON 保留 topLeft、bottomRight，增加 center，图片增加 anchors。

边框与填充分别从蓝、红、橙、绿、青、紫六色选择，填充可关闭，固定 25% 不透明度。选择现有图形时修改该图形，并更新新建图形默认样式；绘图前也可设置新建样式。项目版本保持 2，添加可选 fillColor，兼容旧项目缺失该字段时无填充。任意旧合法六位 HEX 边框仍能读取。界面 SVG 与 PNG Canvas 使用相同的描边、填充及不透明度。

1、2、3 分别切换选择、正方形、圆形；输入框和带 Ctrl / Meta / Alt 的组合键不触发。工具显示快捷键。删除关于坐标面板，保留背景尺寸与底部原图像素提示。

验证覆盖九锚点精度、项目配色兼容、图片与图形标签差异、标签背景透明与层级、颜色编辑和恢复、填充 PNG 像素、快捷键及输入保护。
