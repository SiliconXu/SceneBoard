# 地图缩放和平移

在现有 Vue 编辑器中提供用户请求的滚轮缩放及右键平移。背景和对象共用显示比例和地图平移，不更改保存数据或导出分辨率。

滚轮以鼠标所在点缩放，范围为适应窗口比例的 0.25～16 倍。地图未溢出的轴居中，溢出的轴限制平移，使地图持续覆盖该方向的编辑区。支持滚轮不同 deltaMode。对象拖动、缩放或绘制期间忽略视野缩放，防止手势坐标参考系变化。

右键使用编辑区 Pointer Capture，允许从图片、图形或空白处开始平移，不修改选中对象。未溢出时不平移。松开、取消、失焦、Esc 或窗口变化结束平移。编辑区屏蔽右键菜单。

底部显示当前原图比例和适应窗口按钮。窗口变化保留相对缩放倍率并限制平移；加载背景、打开项目和点击适应窗口恢复居中全图。

浏览器测试验证鼠标锚点、右键平移、平移边界、恢复全图、右键保留选择和缩放平移后的对象坐标转换，同时运行已有编辑与导出回归测试。
