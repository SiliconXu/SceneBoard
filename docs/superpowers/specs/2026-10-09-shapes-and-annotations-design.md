# 命名、图形和标注导出

用户要求坐标向两侧展开、对象命名、Ctrl 绘图和可选标注导出，并确认图形使用空心描边。

## 交互

选中对象时左上角坐标在左上角向左展开，右下角在右下角向右展开；标注在独立覆盖层显示，不会被其他对象遮住。名称从右侧编辑，随所有对象在正下方居中显示，留空隐藏，较长名称在界面中省略。

画布顶部提供选择、正方形、圆形工具。拖拽绘图默认等宽高，Ctrl 改为自由宽高，可在绘图过程中切换。指针捕获支持拖出对象或背景，结果限制在背景内；Esc、失焦、尺寸变化取消正在绘制的草稿，点击不产生零尺寸对象。绘制完成自动回选择工具。已有图形默认保持当前比例缩放，Ctrl 可自由缩放；图片保持比例。

## 存储与导出

Layer 为图片或图形的联合类型，图形类型为 rectangle / ellipse、颜色为六位 HEX；保存版本 2，读取兼容版本 1 图片项目。名称和图形随坐标 JSON 导出，坐标 JSON 增加 kind 字段以区分对象。

PNG 菜单提供包含坐标、包含名称两个独立开关，默认关闭。勾选后标注所有对象，不限于当前选择。Canvas 先绘制所有图片和图形，再绘制全部标注，原始背景分辨率不变；边界处把文字移入背景内以免裁切。不导出选框 / 控制点。名称和两个角坐标的位置遵循界面布局。

## 验证

保留原始拖拽和导出验收，增加命名实时显示、标签左右位置、正方形 / 圆形 / 矩形 / 椭圆绘制、Ctrl 中途切换和自由缩放、图形空心 PNG 像素、标注可选导出、版本 2 图形与名称恢复及版本 1 兼容。纯函数测试覆盖反向绘图、边界、所有角自由缩放和图形数据验证。
