# 拖动距离辅助与键盘微调

用户认可此前提出的拖动辅助设计，并要求方向键微调。距离提示仅对正在拖动的图片启用，仅比较其他图片。以矩形边缘水平 / 垂直间距的欧氏距离选择最近对象，屏幕距离不超过 80 px 时提供提示。数字使用原图像素，显示取整。水平 / 垂直分离时显示各轴间距，重叠时只显示对齐提示。矩形边缘及中心轴在屏幕 3 px 内视为近似对齐，每轴最多一条。辅助线不修改几何数据，无吸附，无存储和导出字段。

SVG 辅助层显示青色虚线对齐和橙色间距标记，固定屏幕字号与线宽。拖动结束、取消、失焦或画布尺寸改变时清除。缩放与图形拖动不显示。

选择模式下方向键移动选中对象 1 个原图像素，Shift 加速至 10。复用既有边界限制，实际位置变化才标记未保存。输入 / 可编辑区域、组合键 Ctrl / Meta / Alt、忙碌和确认状态不触发移动。

测试包括原图间距、缩放阈值、最近对象、反向和对角间距、重叠对齐、自对象排除，以及浏览器拖动提示、松开隐藏、精确微调与输入保护。
