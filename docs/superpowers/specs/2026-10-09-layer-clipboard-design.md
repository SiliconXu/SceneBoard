# 图层复制、剪切和粘贴

提供页面内图层剪贴板，以及右侧复制 / 剪切 / 粘贴按钮，快捷键 Ctrl 或 Meta + C / X / V。输入、选择、可编辑区域及 IME 输入保持原生编辑行为，不触发图层操作。无选中对象时禁用复制与剪切，无背景或剪贴板内容时禁用粘贴，忙碌或背景替换确认时不处理快捷键。

复制取得独立快照，不修改原图层或项目保存状态。剪切保存快照并删除原图层。粘贴生成新 ID、放在最上层、回到选择工具并选中新对象，保留名称、尺寸、比例、图片与图形颜色。普通复制首次偏移 20 像素，重复粘贴依次增加 20；剪切首次偏移 0，后续同样递增。边界处限制位置，较小背景等比例缩小对象。页面内跨项目保留剪贴板，刷新不保留；不写入系统剪贴板。

验证包含无内容禁用、复制快照不受原图改名影响、连续粘贴、剪切首次位置、新 ID、输入框文字剪贴板保护、按钮及快捷键、图形配色保留、缩小背景与边界几何、保存新图层。
