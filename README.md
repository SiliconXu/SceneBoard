# Frame · 图片坐标工作台

使用 Vue 3、TypeScript 和 Vite 的本地图片摆放工具。图片仅在浏览器中读取和处理，不上传服务器。

## 启动

需要 Node.js 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://127.0.0.1:5173）。

```sh
npm test
npm run build
npm run preview
```

浏览器验收测试：`npm run test:e2e`。Windows 默认使用已安装的 Chrome；其他平台先运行 `npx playwright install chromium`。可通过 `PLAYWRIGHT_CHANNEL` 环境变量选择浏览器。

开发交付顺序：先验证网页版并由用户确认，再按用户要求统一打包桌面版。常规网页修改期间不更新桌面便携包。

## Windows U 盘便携版

便携版复用同一套 Vue 编辑器，不需要安装 Node.js 或运行开发服务器。解压发布 ZIP 到 U 盘的一个可写文件夹，双击 `SceneBoard.exe`。请复制整个文件夹，不能只复制 EXE。

```text
SceneBoard/
  SceneBoard.exe
  resources/、locales/、DLL 等运行文件
  data/       设置、浏览器缓存、日志及临时文件（首次运行创建）
  projects/   项目文件默认保存位置
  exports/    PNG、JPEG、WebP 图片和坐标 JSON 默认保存位置
```

应用管理的数据均位于 EXE 所在文件夹及其子文件夹，不使用系统 AppData。保存对话框允许更改文件名和子目录，但禁止保存到便携目录外。项目已嵌入全部背景及对象图片，保存后不依赖原图片路径。图层内部剪贴板仍仅在当前运行期间保留；没有新增自动保存，请在关闭程序或拔出 U 盘前保存项目并退出。系统剪贴板是电脑提供的临时功能，不属于项目存储。

开发者构建 Windows x64 便携包：

```sh
npm run desktop:build
```

输出到 `release/`。桌面本地运行：`npm run desktop:dev`；验证：`npm run test:desktop`。开发运行数据放在项目的 `.portable-dev/`，与 `release/` 一样不会提交到 Git。

## 编辑操作

1. 加载 PNG、JPEG 或 WebP 背景，或创建纯色背景。
2. 添加一张或多张角色 / 物品图片，单击右侧图层卡片里的名称即可修改，Enter 或失去焦点保存，Esc 取消。名称显示在对象正下方，留空则隐藏。第一张图片居中，后续图片依次向右下偏移 20 个原图像素；批量和分次添加都采用该规则，位置限制在背景内。
3. 拖动对象移动，单选四角保持宽高比例缩放；所有对象限制在背景内。通过图层列表选择被遮住的对象，卡片右上角的垃圾桶图标删除对应对象，Delete 或 Backspace 删除选中对象，Esc 取消选择 / 绘制。
4. 画布顶部选择正方形或圆形工具，拖拽绘制空心图形。按住 Ctrl 绘制矩形或椭圆；绘制过程中也可切换 Ctrl。完成一次绘制后自动回到选择工具。已有图形缩放时按 Ctrl 可自由调整宽高；图片始终保持宽高比例。
5. 保存项目，或通过「导出」下载合成 PNG、下载坐标 JSON、复制坐标 JSON。PNG 的「包含坐标」「包含名称」独立选择，默认关闭；勾选后导出所有对象的对应标注。

右击右侧角色 / 物品的图层卡片，选择「导出此对象…」；也可先选中图片，在顶部「导出」菜单选择「导出选中对象…」。菜单显示实际导出尺寸和原图片格式。对象按当前宽高各自四舍五入为整数像素（最小 1 像素）导出，不受地图滚轮缩放影响。仅导出该图片，保留透明留白和 PNG / WebP 的透明、半透明区域，不包含背景、其他对象或标注。PNG、JPEG、WebP 保持原文件格式，文件名包含对象名称和输出尺寸；JPEG 扩展名统一为 `.jpg`。修改对象名称不会改变导出格式。图片会重新采样和编码，不保留原文件元数据或保证与原图逐字节相同；放大不会增加原图细节。图形不提供此导出入口。右键菜单可按 Esc、点击外部或滚动关闭，地图右键拖动仍用于平移。浏览器与桌面版均支持，桌面版默认保存到 `exports/`。

快捷键 **1 / 2 / 3** 分别切换选择 / 正方形 / 圆形工具，在名称输入框中不会触发。绘制前或选中图形后，可在右侧分别设置边框与填充颜色（蓝、红、橙、绿、青、紫），填充固定 25% 不透明度，支持无填充。颜色随项目保存，旧图形项目默认无填充。

按 **A** 打开添加图片对话框（需要先加载背景）；编辑名称时不会触发。

在地图编辑区使用鼠标滚轮缩放，以鼠标位置为中心（地图未超出窗口的方向保持居中）。缩放范围为适应窗口大小的 25%～1600%。地图超出编辑区后，按住鼠标右键拖动平移，边界限制在地图范围内；右键不会改变对象选择或位置。点击右下角「适应窗口」恢复全图视图。窗口大小变化时保留缩放倍率，加载背景或打开项目时恢复全图。缩放和平移仅影响显示，不改变原图坐标或导出结果。

单选或多选对象后，**方向键** 每次移动 1 个背景原图像素，**Shift + 方向键** 每次移动 10 像素，保持在背景范围内。在名称输入框中方向键仅移动文字光标。

拖动图片或图形时，距离其他对象在屏幕上 **30 像素以内**，针对最近对象显示边缘间距辅助线；水平和垂直间距按背景原图像素显示。边缘或中心相差不超过 3 个屏幕像素时显示青色对齐线。重叠时只显示对齐提示，不显示负间距；没有自动吸附。辅助线出现时隐藏名称和坐标标签，松开、取消拖动或失焦后清除。缩放对象不显示该辅助层；辅助线不会保存或导出。

方向键微调时，每一步更新坐标和最近对象的距离。在阈值内同时显示坐标与辅助线，隐藏名称；提示保留至下次操作，超出阈值或改变选择即清除。

图层支持 **Ctrl+C / Ctrl+X / Ctrl+V**（macOS 可用 Command），仅提供快捷键，不占用侧边栏按钮空间。复制 / 剪切保存当时整个选区的独立快照，保留图片、名称、尺寸和颜色；复制不修改项目，剪切移除所选图层。粘贴生成新 ID，保留选区内部层序，放在最上层并整体选中，每次复制粘贴向右下偏移 20 个原图像素；剪切后的首次粘贴保留原位置。超出背景时整体限制位移，粘贴到更小背景时整体等比例缩小，保持相对位置。剪贴板仅保存在当前页面，刷新后清空；可跨当前页面内打开的项目粘贴。在输入框中使用快捷键仍编辑文字。

坐标以背景原始像素计算，左上角为 (0, 0)，X 向右、Y 向下。矩形范围包含透明留白。内部保留小数，界面与坐标 JSON 中的两个端点各自四舍五入为整数。

后添加对象位于上层，列表从上层到下层显示。缩略图左侧的编号按当前列表顺序从 1 开始，拖拽、添加或删除后自动更新。拖曳图层卡片到其他卡片上半部或下半部，插入到其前面或后面；指示线标示插入位置。越靠上的卡片在画布中越靠上。排序同步到项目保存、坐标 JSON 和 PNG 导出，不改变对象位置、尺寸或选择。名称编辑期间不会触发卡片拖拽。

选中的图片在画布上显示中心点坐标；右侧每张图片图层下方默认折叠的「锚点坐标」按 3×3 展示 topleft、midtop、topright、midleft、center、midright、bottomleft、midbottom、bottomright 九个锚点。图形仍显示左上角、右下角坐标，右侧补充中心点。坐标 JSON 包含所有对象的中心点和图片的九个锚点。

名称紧贴对象的下边缘居中显示，留空则隐藏。画布上图片和图形名称均仅在选中且没有距离辅助线时显示。PNG 导出仍按「包含名称」选项绘制所有对象名称，不受选择或辅助线状态影响。名字和坐标标签背景均为半透明。所有名称位于角色 / 物品及图形下方，避免挡住其他角色；坐标的显示层级高于所有对象和名称。PNG 标注同样遵循此层级规则。

保存的 `.frame.json` 项目版本为 3，包含背景类型、全部图片、图形、名称、排列顺序及精确位置 / 尺寸，打开后无需原始文件，仍兼容版本 1、2 项目。纯色背景保存颜色和尺寸，不伪造背景图片。背景替换需要确认并清空叠加对象；无效项目或加载失败不修改当前有效项目。关闭未保存项目时浏览器会提示。

合成 PNG 按背景原始分辨率绘制，不含编辑选框或控制点。先绘制名称，再绘制对象，最后绘制坐标；靠近边缘时把文字移入图片范围，以免裁切。图形按设置的边框与半透明填充导出。暂不支持旋转、裁剪及自动保存；关闭页面前请保存项目。极大图片的处理和导出受浏览器内存及 Canvas 尺寸限制。

## 精确编辑与多选排列

选择对象后，画布下方的独立属性栏显示与当前选择有关的属性，顶部工具栏保持原有结构，右侧列表专注于图层管理。单选显示 X、Y、宽、高，多选显示选中数量、整体 X、Y 及只读的整体宽高；没有选择时隐藏编辑控件，显示简短操作提示。每张图片图层下方的「锚点坐标」默认折叠，可分别展开。图层列表独立滚动。

位置默认按中心点输入，可切换为左上角；切换只改变读数含义，不移动对象。数值以背景原始像素计算，支持小数输入；Enter 或失焦提交，Esc 恢复。X、Y 定位点坐标和锚点坐标统一四舍五入显示整数，内部仍保留精确值；仅查看、失焦或切换定位点不会把显示整数回写到项目。图片始终保持比例，不显示多余的比例复选框；图形的「数值输入保持比例」默认开启，可关闭后分别修改宽高；该开关只影响数值输入，四角拖动仍沿用默认等比、Ctrl 自由缩放图形的规则。空值、非有限数和非正尺寸不提交。位置越界或尺寸过大时限制到画布允许范围，保持所选定位点不动，并提示和显示实际值。

在画布或图层列表中，Shift、Ctrl（macOS 可用 Command）点击可切换对象的选择状态，支持图片与辅助图形混选。选择工具下，在画布空白处拖动进行框选，只有完整矩形（包括透明留白）被包含的对象才会选中；按修饰键框选追加，否则替换选区。空白单击或 Esc 清空选择，Ctrl / Command+A 全选；输入框内这些快捷键只编辑文字。

多选时拖动任一已选对象或使用方向键，整体移动选区并保持相对位置；靠边时整体停止，不会把对象挤到一起。单击已选对象而不拖动则切回单选。多选不提供整体缩放或持久化分组。单个卡片的垃圾桶只删除该对象，Delete / Backspace 删除整个选区；重命名和图片右键导出先切换到对应对象单选。

至少选择两个对象后，可以相对操作前的选区整体外框进行左 / 水平居中 / 右 / 顶 / 垂直居中 / 底对齐。至少选择三个对象后，可进行水平或垂直等间距分布：按该轴的位置排序，固定首尾，均分矩形边缘之间的空隙；同位置按图层顺序稳定排序。空间不足以形成非负间距时禁用，悬停可查看原因。排列不改变对象尺寸或图层顺序。

开发约束：保持界面简洁、操作方便；优先复用入口，按上下文显示操作，复杂信息按需展开。每轮验收同时检查界面复杂度和操作便利性，长期约束见根目录 AGENTS.md。

## 纯色背景

空白页面或顶部背景菜单选择「创建纯色背景」，设置宽高与颜色。默认 800×600、黑色 `#000000`，支持颜色选择器与六位十六进制输入。尺寸须为正整数，每边不超过 32767 像素，总像素不超过 6400 万。

创建后在侧栏「修改背景颜色」，会保留现有角色和图形。尺寸在创建时确定；重新创建画布或换成图片背景时，确认后清空现有图层。纯色画布同样支持编辑、项目保存、合成 PNG 和坐标 JSON；坐标仍以画布左上角为原点。

## 导出 Pygame Zero 项目

顶部「导出 → 导出 Pygame Zero 项目…」可检查名称并预览实际生成的 Python 代码。单个对象的图片导出仍只导出图片。

图片图层名称去掉末尾 `.png`、`.jpg`、`.jpeg`、`.webp` 后，须以小写英文字母开头，仅包含小写字母、数字、下划线，最多 100 个字符。不得重名、使用 Python 关键字、Pygame Zero 内置名称（如 `screen`、`keyboard`）或 Windows 保留文件名。不合规时列出原因，点击「定位修改」进入对应图层名称编辑，不会自动改名。图形名称不受此检查影响。

默认项目名 `pygame_project`，支持修改。浏览器下载 ZIP，解压得到项目文件夹；桌面版选择一个新的文件夹路径，默认放在便携目录 `exports/`，拒绝覆盖已有目录。项目结构：

```text
pygame_project/
  main.py
  images/
    background.png   # 仅图片背景时存在
    cat.png          # 按通过检查的角色名称输出
```

背景图片保持原始尺寸，角色图片按当前宽高分别四舍五入（最小 1 像素），全部编码为 PNG，保留透明留白与半透明区域。纯色背景在 `draw()` 中直接使用 `screen.fill()`，不生成 `background.png`。无角色时也保留空的 `images/`。

`main.py` 只设置窗口尺寸、逐个创建和定位角色、按图层顺序绘制背景及角色。角色中心坐标四舍五入为整数，预览与导出一致，编辑器内部仍保留精确坐标；因坐标、图片尺寸和运行时像素取整，边缘可能有不超过 1 像素的差异。辅助矩形、椭圆、名称、坐标和选框不进入游戏。没有自动生成移动、碰撞、计分、动画或事件处理，也不会修改已有 Python 项目。

在已安装 Python 与 Pygame Zero 的环境，打开 `main.py` 运行，或在项目目录执行 `python main.py`。应用不内置 Python 运行环境。运行验证：先执行 `npm run test:e2e`，再执行 `python scripts/verify-pygame.py`，会用实际 Pygame Zero 渲染图片背景、纯色背景和空场景，检查窗口、颜色、资源尺寸、透明度和遮挡。

精确编辑、多选排列及后续翻转、裁剪、动画素材目标与进度见 [功能路线图](docs/pygame-zero-roadmap.md)。
